# 株式会社〇 コーポレートサイト要件定義書

## 1. プロジェクト概要

株式会社〇のコーポレートサイトをリニューアルする。

株式会社〇が現在行っているAI・システム開発、DX支援、AI教育、人材育成、海外教育などの事業を明確に伝えるとともに、Missionである「幸せに働ける人を世界中に増やす」と、会社が長期的に目指す社会像を表現する。

株式会社〇を、単なるAI開発会社や教育会社としてではなく、高い技術力と社会的価値を両立し、技術、教育、仕事、企業、地域をつなぐ会社として位置づける。

また、100年、500年と継続する企業を目指し、事業内容が将来変化しても使用し続けられるブランド基盤と、拡張性の高いWebサイトを構築する。

---

## 2. サイトの目的

1. 株式会社〇のMission、Vision、思想を伝える。
2. 現在行っている事業内容を分かりやすく伝える。
3. AI・システム開発やDX支援に関する相談を獲得する。
4. 企業、自治体、教育機関、就労支援機関との連携機会を増やす。
5. CSR、地方創生、教育支援、就労支援に関心を持つ企業から、仕事、協賛、共同事業などの相談を獲得する。
6. AIを学びたい人や、場所・身体的条件にかかわらず働きたい人に、学習や仕事への将来的な参加機会を伝える。
7. 株式会社〇の活動、実績、技術力に対する信頼を高める。
8. 100年以上継続する会社として、長期的に使用できるブランド基盤を構築する。
9. プレスリリース、取材実績、メディア掲載情報を継続的に蓄積し、企業としての認知度と信頼性を高める。
10. 記者、編集者、番組制作会社などのメディア関係者が、会社情報や取材素材を確認し、問い合わせしやすい環境を整える。

## 3. Mission

# 幸せに働ける人を世界中に増やす。

株式会社〇のすべての事業は、このMissionを実現するための手段として位置づける。

技術によって仕事や価値を生み出し、教育によってその仕事を担える人を増やし、仕組みによって実際の仕事や社会参加へつなげる。

## 5. Vision

株式会社〇は、次の5つの変化を実現する。

### 1. 「働く」の概念を変える

お金のためだけに働くのではなく、自分の好きなことや得意なことを活かし、誰かの幸せや社会の価値につながる働き方を広げる。

### 2. 組織の概念を変える

規模や利益だけではなく、社員、顧客、地域、社会にどれだけ幸福を生み出したかによって評価される組織を増やす。

### 3. 資本主義の次を作る

資本主義の良さを活かしながら、その弊害を小さくし、お金だけではない価値や幸福も大切にされる新しい仕組みを考え、実践する。

### 4. 世界の教育格差をなくす

住んでいる場所、経済状況、身体的な条件にかかわらず、誰もが質の高い教育を受け、未来の選択肢を広げられる環境をつくる。

### 5. 文化を超えた相互理解を作る

国、文化、言語、価値観の違いを越えて、お互いを知り、尊重し、思いやることのできる関係を育てる。

各Visionの詳細ページまたは詳細セクションでは、簡潔な説明文に加え、3〜5項目程度の具体的な考え方や活動方針を掲載する。

## 10. 第2の柱：AI教育・人材育成

AIを利用するだけでなく、AIを組み込んだシステムやサービスを開発し、仕事として価値を提供できる人材を育成する事業。

### 10.1 主な内容

* AIを活用したプログラミング教育
* AIエージェント開発教育
* AIアプリ・システム開発教育
* Python教育
* Web開発教育
* データ分析・機械学習教育
* 実務を想定したプロジェクト型学習
* 企業向けAI・DX人材育成
* 学生・社会人向け教育
* 海外大学・教育機関との共同教育
* オンライン・仮想空間を活用した教育
* 講師・TA・キャリア支援を含む伴走型教育
* 個人に合わせた学習カリキュラム
* 学習成果物やポートフォリオの制作支援

### 10.2 教育の段階

```text
AIを使う
↓
AIを使ってコードを書く
↓
AIをシステムや仕事に組み込む
↓
実際の課題を解決する
↓
仕事として遂行する
```

### 10.3 教育事業の特徴

一般的な生成AIの操作方法やプロンプトだけを教える教育ではない。

AIを使ってコーディングし、AIエージェントやアプリケーションを開発し、実際の業務や社会課題を解決できる人材を育成する。

AIエンジニアだけを対象とするのではなく、今後あらゆる仕事にAIが活用される時代を前提とする。

対象となる仕事は、ITやシステム開発に限定しない。

* 農業
* 伝統文化
* 地域産業
* 製造業
* 福祉
* 教育
* クリエイティブ
* バックオフィス
* その他のさまざまな仕事

各分野の専門性とAIを組み合わせ、人の可能性と仕事の選択肢を広げる。

### 10.4 AI・しごと学校

教育事業の中心的なブランド・プロジェクトとして、「AI・しごと学校」を展開する。

AI・しごと学校では、AIを学ぶこと自体をゴールにせず、受講者が自分の仕事にAIを活用したり、AIを活用した新しい仕事を行えるようになることを目指す。

校舎や学習環境にはオンライン空間や仮想空間を活用するが、「メタバース」を事業の中心的な訴求にはしない。

### 10.5 この事業の役割

* 高度なAI人材を育成する
* 教育格差を縮小する
* 場所や環境に左右されず学べる機会を提供する
* 企業や社会が必要とする人材を育成する
* 学ぶ人の仕事や人生の選択肢を増やす
* AIをあらゆる仕事で活用できる人を増やす
* 教育から実務への接続を可能にする

### 10.6 ホームページ用の短い紹介文

> AIを使うだけでなく、AIを実装し、実際の仕事を遂行できる人材を育成します。

## 12. 3つの柱の関係

3つの事業は、次のように循環する。

```text
AI・システム開発
企業や社会の課題と仕事を得る
        ↓
AI教育・人材育成
課題を解決できる人材を育てる
        ↓
仕事と社会参加の仕組みづくり
実務・就労・社会参加につなげる
        ↓
新しい実績・課題・仕事が生まれる
        ↓
AI・システム開発へ戻る
```

株式会社〇の強みは、開発、教育、就労を一つの循環として運営することにある。

### Missionとの関係

```text
Mission
幸せに働ける人を世界中に増やす

実現手段
1. 技術によって、仕事と価値を生み出す
2. 教育によって、できる人を増やす
3. 仕組みによって、働ける機会につなげる
```

将来的にAIという言葉や技術が変化した場合でも、第1の柱を「技術・システム開発」へ拡張することで、Missionと事業構造を維持できるものとする。

## 15. 「〇」に込めた思い

会社名の「〇」は、世界中の人が認識しやすい普遍的な記号として採用している。

「〇」には、次の意味を込める。

* 世界共通の記号
* 円
* 人と人とのつながり
* ご縁
* 循環
* 調和
* 肯定
* 正解
* 多様性
* 国や文化を超えた共通性

国境や文化を越えて人と人がつながり、互いの違いを認めながら、一緒に幸せをつくるという考えを表現する。

## 17. モーション・インタラクション要件

### 17.1 基本方針

* 動きは装飾だけでなく、情報理解とブランド表現に使用する
* 「〇」、接続、循環を表現する
* スクロール操作を妨げない
* 読むために待つ必要のある演出を避ける
* スマートフォンでは動きを軽量化する
* prefers-reduced-motionに対応する
* 動きが無効でもすべての情報を理解できるようにする

### 17.2 想定する表現

* ヒーローのMission表示
* 背景の〇の緩やかな動き
* 軽いポインター追従
* セクション表示時のフェード・スライド
* 3事業の接続線アニメーション
* Visionのスクロール切り替え
* プロジェクトカードのホバー
* 写真の軽いズーム
* ボタンや矢印のホバー
* ページ遷移時の短い円形アニメーション

### 17.3 実装技術の想定

* CSS Transition / Animation
* Framer Motion
* Intersection Observer
* GSAP ScrollTriggerは複雑なスクロール演出に限定
* SVGアニメーション

Three.jsやWebGLは、明確な効果がある場合に限り検討し、基本実装には使用しない。

## 23. Claude Codeでの実装ルール

Claude Codeは、本要件定義書とFigmaのDesktop版、Mobile版、Design Foundationsを参照して実装する。

### 作業方針

* 最初に既存コードと資料を確認する
* 実装前に作業計画を提示する
* 大きな変更を一度に行わない
* セクション単位で実装する
* 指定された対象以外を不用意に変更しない
* 各作業後にLintとBuildを実行する
* エラーや警告を無視しない
* Figmaとの差異が必要な場合は理由を説明する
* 動きより先に静的レイアウトを完成させる
* DesktopとMobileを同じ作業単位で確認する
* アクセシビリティを後付けにしない
* 作業単位ごとにGitコミット可能な状態を維持する

### 基本確認コマンド

```bash
npm run lint
npm run build
```

### 実装順序

1. プロジェクト基盤
2. デザイントークン
3. フォント
4. 共通レイアウト
5. Header
6. Hero
7. トップページ各セクション
8. レスポンシブ調整
9. モーション
10. 下層ページ
11. 問い合わせフォーム
12. ニュース・プレス
13. SEO・OGP・構造化データ
14. アクセス解析
15. 最終的なパフォーマンス・アクセシビリティ確認
